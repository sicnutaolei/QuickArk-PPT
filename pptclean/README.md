# pptclean —— PPT 课件文件名清洗工具（Go）

一个用 Go 编写、可复用的命令行小工具，专门解决课件文件名在 Windows「按名称排序」时的顺序错乱问题。

## 核心功能

把文件名里 `第<数字><单位>` 形式的编号，统一归一为零填充的阿拉伯数字：

- `第九章　第31讲　……` → `第09章　第31讲　……`
- `第八章　第30讲　……` → `第08章　第30讲　……`

为什么需要它：Windows「按名称排序」是逐字符（Unicode 码位）比较，而 `九`(U+4E5D) 的码位其实**小于** `八`(U+516B)，所以朴素的排序会把「第九章」排到「第八章」**前面**，顺序全乱。本工具把编号改成零填充阿拉伯数字后，纯靠数字本身即可正确排序；阿拉伯数字（如 第5讲 → 第05讲）也会一并补零，保证 `第05讲` 排在 `第12讲` 之前。

## 特性

- **中文数字解析**：支持 `十一 / 二十 / 二十一 / 一百 / 一百零五 / 一千零一` 等
- **零填充宽度自动对齐**：取目录内最大数字位数（下限 2 位），保证 `09 < 10`、`99 < 100`
- **可识别单位可配置**：默认 `章 / 讲 / 节 / 课 / 单元 / 篇 / 部分 / 回 / 幕`，可用 `--units` 覆盖
- **安全**：默认先 dry-run 预览，确认后才真正改名
- **无编号文件保留**：像 `封面.pptx`、`目录.pptx` 这类没有可识别编号的文件保持原样，并在报告中单独列出
- **冲突处理 + 回滚**：重名自动加 `_N` 后缀；改名后生成 CSV 映射，`undo` 命令可一键还原

## 用法

```bash
# 构建（需要 Go 1.25+）
cd pptclean
go build -o pptclean.exe ./cmd/pptclean

# 运行：不带目录会交互式提示输入；也可直接跟目录参数
./pptclean "D:\课件\2027版 步步高 大一轮 化学\教师用书配套课件"

# 跳过确认直接执行
./pptclean --yes "目录路径"

# 回滚上一次改动（CSV 由上次运行生成）
./pptclean undo pptclean_rename_YYYYMMDD_HHMMSS.csv
```

仅处理**当前目录**下的 `.ppt` / `.pptx`，不递归子目录、不改动无编号文件、不移动文件。

## 与仓库根目录 QuickArk_PPT.py 的区别

本仓库包含两个**功能不同**的工具，请按需选用：

| 对比项 | pptclean（本目录，Go） | QuickArk_PPT.py（仓库根，Python） |
| --- | --- | --- |
| 做什么 | **只改文件名**：把编号数字标准化，让按名称排序正确 | **整理目录结构**：按章节 / 知识点把 PPT 移动、归类到 `第X章 / 第X节` 文件夹 |
| 是否移动文件 | 否，原地重命名 | 是，会创建文件夹并移动文件 |
| 典型用途 | 只想在资源管理器里按顺序查看课件 | 想把杂乱课件按章节归档成清晰目录 |
| 语言 / 依赖 | Go，零依赖，编译后为单文件 | Python，标准库即可运行 |

两个工具互不冲突，可分别或配合使用（例如先用 pptclean 规整文件名，再用 QuickArk_PPT.py 归类归档）。
