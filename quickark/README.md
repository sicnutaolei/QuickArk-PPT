# quickark —— PPT 课件按章节归类归档（Go 版）

`QuickArk_PPT.py` 的 **Go 重构版**。把目录里的课件 PPT 按「章 / 节（或讲）」自动建文件夹并归类进去。

## 与原 Python 版的区别

| | quickark（Go，本工具） | QuickArk_PPT.py（Python，原版） |
| --- | --- | --- |
| 章节范围 | **任意**章/节（阿拉伯或中文数字） | 仅第一~第五章、第一~第五节 |
| 文件夹命名 | 零填充阿拉伯（`第09章`、`第31讲`） | `第9章`、`第3节`（中文数字） |
| 排序正确性 | ✅ 已根治「第九章」排到「第八章」前的 bug | ❌ 受 Windows 逐字符排序影响 |
| 扩展名 | `.ppt` 与 `.pptx` | 仅 `.pptx` |
| 安全机制 | dry-run 预览 + 确认 + CSV 映射 + `undo` 回滚 | 无 |
| 目录来源 | 命令行参数 / 交互式输入 | 当前工作目录 |

## 核心功能

- 解析文件名中的 `第<数字>章` 与 `第<数字>节`（或 `第<数字>讲`），数字支持阿拉伯（11）和中文（十一 / 二十 / 一百零五）。
- 特殊节名无需数字也能识别：`整理与提升`、`复习课`、`提升课`。
- 生成的目录结构示例：
  ```
  第08章/
    第30讲/
  第09章/
    第31讲/
    整理与提升/
  ```
- 零填充宽度按目录内最大数字自动对齐（下限 2 位），保证 `09 < 10`、`99 < 100`。
- 同名冲突自动加 `_N` 后缀；无法解析章节的文件（如 `封面.pptx`）跳过并单列。

## 用法

```bash
# 构建
cd quickark
go build -o quickark.exe ./cmd/quickark

# 整理指定目录（先预览，输入 y 确认后才移动）
./quickark "D:\课件\2027版 步步高 ...\教师用书配套课件"

# 未传目录时，会交互式提示输入
./quickark

# 跳过确认直接执行
./quickark "目录路径" --yes

# 撤销：按生成的 CSV 映射把文件移回原位，并清理空目录
./quickark undo quickark_organize_20260815_121132.csv
```

- `--yes` / `-y`：跳过确认，直接执行。
- `undo <csv>`：读取映射文件回滚；映射文件在每次执行后生成于被整理的目录内。

## 与 pptclean 的配合

典型流程：先用 [`pptclean`](../pptclean) 规整文件名（让章节/讲次数字正确），再用本工具把课件按章节归类进文件夹。

## 说明

- 仅处理当前目录，不递归子目录。
- 移动采用 `os.Rename`；跨磁盘时自动回退为「拷贝 + 删除」。
- 这是独立 Go 模块（`module quickark`），不依赖 `pptclean`。
